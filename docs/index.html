Choose what rides the tunnel.

Routing

Honest paths, not cargo-cult VPN theater.

Allowed IPs still define what the peer can carry. Fairlead decides which of your traffic actually uses the tunnel — by address, domain, or running app.

  1. 01

    WireGuard & AmneziaWG

    One client for both. Import .conf, JSON shares, or Amnezia vpn:// links. Amnezia configs show an AmneziaWG badge.

  2. 02

    Direct / Through

    Exclude a list from the tunnel, or send only that list through it. Rules apply while connected — the engine restarts cleanly so routes stay honest.

  3. 03

    Apps, domains, LAN

    Match programs by path, keep local network off the tunnel, and optionally block QUIC so browsers stay on TCP when you need them to.

  4. 04

    Status you can trust

    Connected means the system path actually uses the tunnel. Live rates, totals, and menu bar / tray so closing the window never drops you.

Product

Built like a tool, not a brochure.

Configs stay on this computer. Keys never leave. The helper elevates only to manage the tunnel.

Routes that mean something

Add IPs, domains, or apps. Flip Direct and Through without rewriting the peer config. Each rule can sleep without being deleted.

Configs as fields or text

Edit the tunnel as structured fields, or drop into the raw WireGuard / AmneziaWG text when you want the full surface.

Quiet defaults

Open at login, start hidden, pick a default tunnel, set the language. Eight locales plus Auto that follows the system.

Get Fairlead

Download the build for your machine.

Unzip and run. First connect installs a helper with administrator rights; later connects do not ask again. Builds from GitHub are not notarized — Gatekeeper / SmartScreen may warn once.

macOS 15+

Move Fairlead.app to Applications. Helper returns after reboot.

Windows 10 / 11

Keep the unzipped folder intact next to Fairlead.exe.
